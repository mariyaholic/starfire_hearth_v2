# M2B actual-control QA

Godot 4.7.2, native Xvfb/software OpenGL. **Initial setup is a synthetic fixture, not ordinary campaign play:** `seed_fixture.gd` builds current M2A seed 17 at Month 2, puts Construction one normal travel turn from Halden, leaves the Survey Probe idle, marks Tessel known, and sets Minerals to 490 and Energy to 300. The normal save serializer writes it to isolated user data. From Continue onward, all actions below use actual OS pointer/keyboard controls. The observer only reads UI geometry/state and takes screenshots; it never applies gameplay actions.

Verified and visually inspected:

- Continue → Galaxy → Fleet Travel → Start auto-explore. Enabled/waiting appears (`02-auto-enabled-desktop.png`). Actual End Turn assigns travel to Tessel and advances the probe's leg to progress 1.
- The same actual turn reaches Halden and opens “A Quiet Cache” (`03-halden-event-desktop.png`). All three choices, Energy costs 15/20, +40 Minerals, +50% research for 10 turns, and the prose warning about storage limits are readable. Forced reference-phone 2400×1080 / 200% text is scrollable without horizontal clipping (`04`, `05`, `06`). This is layout simulation, not a physical phone.
- Actual Study choice reduces queued-preview Energy from 309 to 289. Reopen Fleet Travel: automation is travelling with two turns remaining (`07`). Actual Stop auto-explore changes to disabled while preserving the path `[sys_tessel]` and progress 1 (`08`). Paired `07-observation.json` / `08-observation.json` record that unchanged journey. The stopped toggle and explanation fit phone 200% after actual wheel scrolling (`09`).
- Re-enable through the UI, resolve a further turn, then Menu → Save game → Quit to title → Continue. Reopened Fleet Travel retains enabled automation, travel path and progress 2 / one turn remaining (`10`). The actual saved Month 4 state records `m2a_halden_resolved` and `m2a_halden_study`; the research modifier is 5000 basis points with 9 turns remaining after the follow-up turn.
- Actual Galaxy → Halden navigation shows “A dormant beacon” and “There are no planets in this system” in 3D (`11`) and Strategic (`12`). This removes the prior impossible “Choose a planet” hint. Before screenshots are `../halden-before/03-empty-halden-strategic.png` and `04-empty-halden-3d.png`; those came from an older real-play save and lack the later canonical beacon data.
